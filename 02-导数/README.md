> 状态：⚪ 未开始

## 一、本章知识框架

1. **导数与微分的概念**
   - 导数定义（增量比的极限）、左导数与右导数
   - 导数的几何意义（切线斜率）与物理意义
   - 可导与连续的关系（可导 ⇒ 连续，反之不成立）
   - 微分的定义与几何意义（dy = f′(x)dx）
2. **导数与微分的计算**
   - 基本求导公式表
   - 四则运算、复合函数链式法则
   - 反函数求导、隐函数求导
   - 参数方程求导（一阶、二阶）
   - 对数求导法、幂指函数求导
   - 高阶导数（常用 n 阶导、莱布尼茨公式）
3. **微分中值定理**
   - 费马引理、罗尔定理、拉格朗日中值定理、柯西中值定理
   - 泰勒公式（拉格朗日余项、佩亚诺余项）与麦克劳林展开
   - 中值定理证明题的常用构造思路
4. **导数的应用**
   - 洛必达法则
   - 单调性、极值（一阶／二阶判别法）
   - 最值问题与实际问题优化
   - 凹凸性与拐点
   - 渐近线（水平、铅直、斜渐近线）
   - 曲率与曲率半径
   - 函数作图
