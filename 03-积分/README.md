# 第 3 章　积分

> 状态：⚪ 未开始

## 一、本章知识框架

1. **不定积分**
   - 原函数与不定积分的概念、基本积分表
   - 第一类换元法（凑微分）
   - 第二类换元法（三角代换、根式代换、倒代换）
   - 分部积分法
   - 有理函数与三角函数有理式的积分
2. **定积分**
   - 定积分的定义（黎曼和）与几何意义
   - 可积条件与定积分的性质
   - 变限积分及其求导（微积分基本定理）
   - 牛顿—莱布尼茨公式
   - 定积分的换元法与分部积分法
   - 对称区间、周期函数的积分技巧
3. **反常积分**
   - 无穷区间上的反常积分
   - 无界函数的反常积分（瑕积分）
   - 敛散性判别（比较判别法、p 积分）
4. **定积分的应用**
   - 平面图形面积（直角坐标、极坐标）
   - 旋转体体积（圆盘法、柱壳法）与旋转曲面面积
   - 平面曲线弧长
   - 物理应用（变力做功、水压力、形心、平均值）
5. **补充：常微分方程**
   - 基本概念（阶、通解、特解、初始条件）
   - 一阶方程：可分离变量、齐次方程、一阶线性方程（公式法）
   - 可降阶的高阶方程
   - 二阶常系数线性方程：齐次通解、非齐次特解（待定系数法）

> 说明：微分方程与积分计算关联紧密（数二常考综合题），暂放在本章下。若内容变多，可单独拆分为「05-常微分方程」。
