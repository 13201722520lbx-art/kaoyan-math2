# 考研数学二 · 学习与答疑工作区

用于考研数学（数二）的学习笔记、AI 答疑记录与辅助图表的统一归档。

- **学习材料**：`讲义/高数讲义（数二全）.pdf`（提问时可按需截图给我）
- **当前进度**：第 1 章　极限
- **使用方式**：我提问 → AI 解答并落地成文件 → 按章节归档，便于日后复习

---

## 一、目录结构

```
考研/
├── README.md                # 本文件：总览、导航、使用约定
├── 讲义/                     # 原始讲义 PDF
├── 01-极限/                  # 第 1 章　极限
│   ├── README.md            #   本章知识框架 + 问题索引
│   ├── 笔记/                 #   知识点整理
│   ├── 答疑/                 #   我的问题 + AI 解答
│   └── 图表/                 #   函数图像、示意图、思维导图等
├── 02-导数/                  # 第 2 章　导数
├── 03-积分/                  # 第 3 章　积分
└── 04-线性代数/               # 第 4 章　线性代数
```

> 四个章节目录结构完全一致（`笔记 / 答疑 / 图表`），新内容一律放进对应章节，保证清晰可查。
> 若后续需要拆分，可再增设章节（如「05-微分方程」「06-多元微分」），在此处登记即可。

---

## 二、使用约定

1. **一切文件产物都分章节归档**，命名规则：`章节/子类/序号-标题.md`，例如
   `01-极限/答疑/001-两个重要极限的推导.md`。
2. **答疑记录**同时登记到对应章节 `README.md` 的问题索引表中，方便按章节顺序回看。
3. **图表**：涉及函数图像、几何示意、思维导图等，输出到 `章节/图表/`，并在笔记中引用。
4. 提问时若引用讲义，可直接截图；我会结合截图内容作答，不主动通读整本 PDF。
