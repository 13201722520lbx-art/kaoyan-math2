# 第 4 章　线性代数

> 状态：⚪ 未开始

## 一、本章知识框架

1. **行列式**
   - 行列式的定义与性质
   - 按行（列）展开、余子式与代数余子式
   - 特殊行列式的计算（三角形、范德蒙德等）
   - 克拉默法则
2. **矩阵**
   - 矩阵的概念与运算（加减乘、转置、方阵的幂、伴随矩阵）
   - 逆矩阵（定义、性质、伴随矩阵法、初等变换法）
   - 分块矩阵
   - 初等变换与初等矩阵
   - 矩阵的秩
3. **向量**
   - 向量的线性组合与线性表示
   - 向量组的线性相关与线性无关
   - 极大线性无关组与向量组的秩
   - 向量空间（数二要求较浅）
4. **线性方程组**
   - 齐次线性方程组：解的结构、基础解系
   - 非齐次线性方程组：有解条件、通解结构
   - 由秩判定解的存在性与个数
5. **特征值与特征向量**
   - 特征值与特征向量的定义、性质与求法
   - 相似矩阵与可相似对角化条件
   - 实对称矩阵的特征值与特征向量（正交对角化）
6. **二次型**
   - 二次型及其矩阵表示
   - 合同变换与合同矩阵
   - 标准形与规范形（配方法、正交变换法）
   - 正定二次型与正定矩阵的判别
