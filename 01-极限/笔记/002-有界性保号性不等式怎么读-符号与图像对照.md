## ① ④ 有界性

**符号版**：lim_{x→x₀} f(x) = A ⇒ ∃M > 0，∃δ > 0，当 0 < |x−x₀| < δ 时 |f(x)| ≤ M

| 符号 | 念法 | 图上的东西 |
| --- | --- | --- |
| `∃M > 0` | 存在正的 M | 两条平行线 y = M 与 y = −M |
| `0 < \|x−x₀\| < δ` | δ 窗口 | 蓝色竖带 |
| `\|f(x)\| ≤ M` | 函数值的绝对值不超过 M | 窗口内那段曲线（深色）整段落在两条线之间 |

**证明的抓手（图上就是那条橙色带子）**：

1. 取 **ε = 1**（随便哪个正数都行，取 1 最省事）；
2. 由定义，有 |f(x) − A| < 1；
3. 于是 |f(x)| ≤ |A| + 1，**令 M = |A| + 1**。

所以 M 不是「找」出来的，是**算**出来的 —— 这才是「M 一定存在」的真正含义。

**两个要点**：

- **M 依赖窗口大小**：窗口拉大，窗口内的 max|f| 会变大，原来的 M 可能就不够用了。但没关系，换一个更大的 M 仍然成立 —— 「存在一个 M」永远为真。
- **真正会崩的地方**：窗口逼近函数跑向无穷的位置（如 1/x 在 0 附近），此时无论 M 多大都兜不住，而那里的极限本来就不存在。

**易错点**：

- 只保证**局部**有界，不保证整体（1/x 在 x₀ = 1 处局部有界，在 (0,1) 上整体无界）。
- **反向不成立**：局部有界 ⇏ 极限存在。反例 sin(1/x) 在 0 附近 —— 曲线被 ±1 稳稳夹住，却在 −1 与 1 之间来回狂震，极限不存在。**夹得住 ≠ 安定得下来。**

## ② ⑤ 保号性

### 正向：A 的符号 → 附近函数值的符号

**符号版**：lim f(x) = A > 0 ⇒ ∃δ > 0，当 0 < |x−x₀| < δ 时 f(x) > 0

| 符号 | 念法 | 图上的东西 |
| --- | --- | --- |
| `A > 0` | 极限为正 | A 水平线与那个空心点 (x₀, A) |
| `取 ε = A/2` | 把 ε 取成 A 的一半 | 橙色带子的**下沿正好落在 A/2** |
| `0 < \|x−x₀\| < δ` | δ 窗口 | 蓝色竖带 |
| `f(x) > 0` | 函数值为正 | 0 到 A/2 之间的**绿色安全区** |

**证明就是「取 ε = A/2」这一下**：带子里 |f − A| < A/2 ⇒ f > A/2 > 0。
因为带子**整条都压在 0 上方**，窗口里的曲线自然也都在 0 上方 —— 这就是「保号」。

**图上要盯住的**：0 到 A/2 之间那段**绿色距离**。它非零，保号性才成立。

### 反向：附近 f ≥ 0 ⇒ 只能得 A ≥ 0

**符号版**：附近 f(x) ≥ 0 ⇒ lim f(x) ≥ 0（**不是 > 0**）

**反例**：f(x) = 0.8x²，x₀ = 0。

- 去心邻域内处处 f(x) > 0 ✓
- 但 lim f = **0**，并不 > 0 ✗

**为什么图上就崩了**：A = 0 时 ε = A/2 = 0，**根本不存在「带子下沿」**，绿色安全区的宽度变成 0。
函数值可以永远比 0 大一点点，但「一点点」越来越小，极限正好落在 0 上 —— 严格号被磨平。

## ③ ⑥ 不等式关系

**符号版**：lim f = A，lim g = B，且 A > B ⇒ ∃δ > 0，当 0 < |x−x₀| < δ 时 f(x) > g(x)

| 符号 | 念法 | 图上的东西 |
| --- | --- | --- |
| `A > B` | 两个极限分高低 | 左边两条虚线的高度 |
| `取 ε = (A−B)/2` | ε 取差值的一半 | 两条带子（橙归 f、粉归 g）**刚好贴合** |
| `m = (A+B)/2` | 贴合处的高度 | 中间那条**共享边** |
| `附近 f(x) > g(x)` | 附近 f 在 g 上方 | 窗口内 f 的深色段在上带、g 的深色段在下带 |

**为什么 ε 必须取 (A−B)/2**：

若 ε < (A−B)/2，两条带子之间会留缝，缝里 f、g 谁高谁低说不准；
取 **ε = (A−B)/2** 时 A − ε = B + ε = (A+B)/2，两条带子的边缘**正好重合**，
于是窗口内 f > m 且 g < m，**f > g 被逼了出来**。这就是「令 h = f − g，套用 ⑤」在图上长什么样。

**两层「局部」要分清**：

- 正向上式保证的**只是窗口以内**；
- 窗口外两条曲线照样可以交叉 —— 交互演示里把 A−B 调小，**δ 会自动跟着变窄**，交叉点始终留在窗口之外。

### 反向

**符号版**：附近 f(x) ≥ g(x) ⇒ 只能得 A ≥ B

**反例**：f(x) = 0.5 + 2.5x²，g(x) = 0.5。

- 去心邻域内处处 f(x) > g(x) ✓
- 但 lim f = lim g = 0.5，**A = B**，并不 A > B ✗

## ④ 三条放在一起

| 性质 | 已知 | 可得 | 图上的关键物 | ε 取什么 | 反向成立吗 |
| --- | --- | --- | --- | --- | --- |
| ④ 有界性 | lim f = A 存在 | ∃M, δ：窗口内 \|f\| ≤ M | 两条平行线 ±M | ε = 1（随便） | ✗ sin(1/x) |
| ⑤ 保号（正向） | A > 0 | 附近 f > 0 | 0 到 A/2 的绿色安全区 | ε = A/2（必须精确） | ✗ 0.8x² |
| ⑤ 保号（反向） | 附近 f ≥ 0 | A ≥ 0 | — | — | — |
| ⑥ 不等式（正向） | A > B | 附近 f > g | 两带共用的边 m | ε = (A−B)/2（必须精确） | ✗ 0.5+2.5x² |
| ⑥ 不等式（反向） | 附近 f ≥ g | A ≥ B | — | — | — |

**统一口诀**：

> 三条都是「ε 带 → δ 窗口」这一个机制；
> ④ 的 ε 随便取，⑤ 和 ⑥ 的 ε **必须**取成让带子正好顶住关键位置的那个数。
>
> **从极限推函数，严格号保得住；从函数推极限，严格号必然降级。**

**做题直觉**：题目若让你证 A > 0（或 A > B），条件里一定还有别的信息可用；只有「≥」才是白送的。
