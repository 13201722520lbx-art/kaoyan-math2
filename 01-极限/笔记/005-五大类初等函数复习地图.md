## 一、关系地图：这五类是怎么串起来的

```
                    基本初等函数（5 类）
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
   幂函数 x^a          指数函数 a^x  ⇄  对数函数 logₐx
   （自成一族）         （互为反函数，图像关于 y = x 对称）
                            │
                    三角函数 sin/cos/tan  ⇄  反三角函数 arcsin/arccos/arctan
                            （互为反函数，但需限制定义域取主值分支）
```

**这五类经「四则运算 + 复合」生成的，全叫初等函数**——这就是数二考题的全部范围。

## 二、幂函数　y = x^a

### 三条一次记完的规律

1. **a &gt; 0** → 图像过 (0, 0)，在 (0, +∞) 单调**增**；**a &lt; 0** → 不过原点，在 (0, +∞) 单调**减**。
2. **无论 a 是多少，都过 (1, 1)**——因为 1 的任何次方都是 1。
3. **a 为偶数 → 偶函数**（关于 y 轴对称）；a 为奇数 → 奇函数（关于原点对称）。

### 六个必记的

| 函数 | 定义域 | 值域 | 奇偶 | 单调性 | 恒过的点 |
| --- | --- | --- | --- | --- | --- |
| y = x | ℝ | ℝ | 奇 | 增 | (0,0), (1,1) |
| y = x² | ℝ | [0, +∞) | 偶 | (−∞,0)↓　(0,+∞)↑ | (0,0), (1,1), (−1,1) |
| y = x³ | ℝ | ℝ | 奇 | 增 | (0,0), (1,1), (−1,−1) |
| y = √x = x^(1/2) | [0, +∞) | [0, +∞) | 非奇非偶 | 增 | (0,0), (1,1) |
| y = 1/x = x^(−1) | x ≠ 0 | y ≠ 0 | 奇 | 两支各自减 | (1,1), (−1,−1) |
| y = 1/x² = x^(−2) | x ≠ 0 | (0, +∞) | 偶 | (−∞,0)↑　(0,+∞)↓ | (1,1), (−1,1) |

> **易错**：`y = x^(1/2)` 的定义域是 `[0, +∞)`，因为负数的平方根不是实数。同理，负数的**非整数次幂**在实数范围内都无定义——这是求定义域题的常见坑。

## 三、指数函数　y = a^x　(a &gt; 0, a ≠ 1)

### 图像要点

| 项目 | 内容 |
| --- | --- |
| 定义域 | ℝ |
| 值域 | **(0, +∞)** —— `a^x` 恒为正，**绝不为零** |
| 恒过点 | **(0, 1)** —— 与 a 无关 |
| 参考点 | (1, a)，用来判断陡峭程度 |
| 单调性 | a &gt; 1 → 增；0 &lt; a &lt; 1 → 减 |
| 渐近线 | y = 0（x 轴），**永远取不到** |
| 对称性 | `y = a^x` 与 `y = (1/a)^x` 的图像关于 **y 轴**对称 |

**一句话图像印象**：无论 a 取多少，曲线都从 (0,1) 这个「钉死的点」出发，a &gt; 1 时向右上冲，0 &lt; a &lt; 1 时向右下掉，左边都无限贴近 x 轴。

### 运算律

| 公式 | 白话 |
| --- | --- |
| a^m · a^n = a^(m+n) | 同底相乘 → 指数相加 |
| a^m / a^n = a^(m−n) | 同底相除 → 指数相减 |
| (a^m)^n = a^(mn) | 幂的幂 → 指数相乘 |
| (ab)^n = a^n b^n | 积的幂 → 分别乘方 |
| a^0 = 1　(a≠0) | 任何非零数的 0 次方 = 1 |
| a^(−n) = 1/a^n | 负指数 → 取倒数 |
| a^(m/n) = ⁿ√(a^m) | 分数指数 → 根式 |
| **a^x = e^(x·ln a)** | **求导／积分遇到 a^x 的第一步** |

---

## 四、对数函数　y = logₐx　(a &gt; 0, a ≠ 1)

### 图像要点

| 项目 | 内容 |
| --- | --- |
| 定义域 | **(0, +∞)** —— 真数必须为正 |
| 值域 | ℝ |
| 恒过点 | **(1, 0)** —— 与 a 无关 |
| 参考点 | (a, 1) |
| 单调性 | a &gt; 1 → 增；0 &lt; a &lt; 1 → 减 |
| 渐近线 | x = 0（y 轴），是**垂直**渐近线 |
| 与指数的关系 | 是 `y = a^x` 的反函数，图像关于 **y = x** 对称 |

**一句话图像印象**：它是指数曲线沿 y = x 翻折过来的。恒过 (1,0)，右边慢慢往上爬（或往下掉），左边贴着 y 轴往下（或往上）扎，**永远碰不到 y 轴**。

### 运算律

| 公式 | 白话 |
| --- | --- |
| logₐ(MN) = logₐM + logₐN | **积 → 和**（对数被发明的理由：把乘法变加法） |
| logₐ(M/N) = logₐM − logₐN | 商 → 差 |
| **logₐ(M^n) = n · logₐM** | **把指数拉下来**（处理幂指函数必用） |
| logₐ1 = 0；logₐa = 1 | 两个基本值 |
| logₐb = ln b / ln a | 换底，统一到 e |
| a^(logₐN) = N | 指数与对数互相抵消 |

### 增长阶（x → +∞，抓大头全靠它）

$$\ln x \;\ll\; x^a \;\ll\; a^x \;\ll\; x^x$$

念法：**对数最慢，幂函数中间，指数最快**。

## 五、三角函数

### 图像要点

| 函数 | 定义域 | 值域 | 周期 | 奇偶 | 关键 |
| --- | --- | --- | --- | --- | --- |
| y = sin x | ℝ | [−1, 1] | 2π | 奇 | 过原点，0 附近像直线 y = x |
| y = cos x | ℝ | [−1, 1] | 2π | 偶 | = sin(x + π/2)，左移 π/2 得到 |
| y = tan x | x ≠ π/2 + kπ | ℝ | π | 奇 | 垂直渐近线 x = π/2 + kπ |

### 特殊角（只背第一象限）

| θ | 0 | π/6 | π/4 | π/3 | π/2 |
| --- | --- | --- | --- | --- | --- |
| **sin θ** | 0 | 1/2 | √2/2 | √3/2 | 1 |
| **cos θ** | 1 | √3/2 | √2/2 | 1/2 | 0 |
| **tan θ** | 0 | √3/3 | 1 | √3 | 不存在 |

> **记忆钩子**：sin 的值依次是 `√0/2, √1/2, √2/2, √3/2, √4/2`——根号里就是 0,1,2,3,4。
> cos 那一行把 sin **倒着念**。其余角一律用「奇变偶不变，符号看象限」推。

### 必背恒等式

| 名称 | 公式 | 什么时候用 |
| --- | --- | --- |
| 平方和 | sin²x + cos²x = 1 | 化简根号、凑平方 |
| 商数 | tan x = sin x / cos x | 把 tan 换成 sin/cos |
| 和差角 | sin(a±b) = sin a cos b ± cos a sin b | 拆角、凑角 |
| 二倍角 | sin 2x = 2 sin x cos x；cos 2x = cos²x − sin²x | 升降次 |
| **降次** | sin²x = (1 − cos 2x)/2；cos²x = (1 + cos 2x)/2 | **积分里把平方降成一次** |

## 六、反函数与反三角函数

### 三个性质

1. **存在性**：有反函数 ⟺ 一一映射。**严格单调**是充分条件。
2. **定义域值域互换**：f⁻¹ 的定义域 = f 的值域；f⁻¹ 的值域 = f 的定义域。
3. **互逆抵消**：f⁻¹(f(x)) = x；f(f⁻¹(x)) = x。

**图像**：y = f(x) 与 y = f⁻¹(x) 关于 **y = x** 对称（点 (a,b) ↔ (b,a)）。

### 反三角函数（值域区间最重要，错了全错）

| 函数 | 定义域 | 值域（主值区间） | 端点 | 奇偶 |
| --- | --- | --- | --- | --- |
| y = arcsin x | [−1, 1] | **[−π/2, π/2]** | 取得到 | 奇 |
| y = arccos x | [−1, 1] | **[0, π]** | 取得到 | 非奇非偶 |
| y = arctan x | ℝ | **(−π/2, π/2)** | **取不到** | 奇 |

> **核心信息**：arcsin / arccos 是**闭区间**，arctan 是**开区间**。
> 所以只能写 `lim(x→+∞) arctan x = π/2`，**绝不能写** `arctan(+∞) = π/2`。

### 常用恒等式

| 恒等式 | 注意 |
| --- | --- |
| arcsin x + arccos x = π/2 | x ∈ [−1, 1] |
| arctan x + arccot x = π/2 | x ∈ ℝ |
| **arctan x + arctan(1/x) = π/2 (x&gt;0)；= −π/2 (x&lt;0)** | **易错重灾区，符号分情况** |
| arccos(−x) = π − arccos x | arccos 不是奇函数 |
| arcsin(−x) = −arcsin x，arctan(−x) = −arctan x | 这两个是奇函数 |

## 七、指对互换（最容易忘，但一句话就能捡回来）

$$\boxed{\;a^{\,b} = N \quad \Longleftrightarrow \quad \log_a N = b\;}$$

**「a 的 b 次方等于 N」和「以 a 为底 N 的对数是 b」说的是同一件事。**

| 指数形式 | 对数形式 | 说明 |
| --- | --- | --- |
| 2³ = 8 | log₂8 = 3 | 底数 2 不动，3 和 8 换位置 |
| 10² = 100 | lg 100 = 2 | lg 表示以 10 为底 |
| e⁰ = 1 | ln 1 = 0 | ln 表示以 e 为底 |
| a^(logₐN) = N | logₐ(a^b) = b | 互相抵消 |
| e^(ln x) = x　(x&gt;0) | ln(e^x) = x | 最常用的两个特例 |

> **口诀**：**底数不动，指数与真数换位。**

**常用数值**：e ≈ 2.718、e² ≈ 7.389、1/e ≈ 0.368、ln2 ≈ 0.693、ln3 ≈ 1.099、ln10 ≈ 2.303

## 八、图像变换（改一个系数，图怎么动）

| 变换 | 写法 | 图像怎么动 | 口诀 |
| --- | --- | --- | --- |
| 纵向平移 | y = f(x) + c | c&gt;0 向上，c&lt;0 向下 | **上加下减** |
| 横向平移 | y = f(x + b) | b&gt;0 向**左**，b&lt;0 向**右** | **左加右减**（与直觉相反） |
| 纵向伸缩 | y = A·f(x) | \|A\|&gt;1 拉伸，\|A\|&lt;1 压缩 | A 管高度 |
| 横向伸缩 | y = f(kx) | k&gt;1 **压缩**，k&lt;1 拉伸 | **k 管胖瘦**（与直觉相反） |
| 关于 x 轴翻折 | y = −f(x) | 上下翻转 | 负号在外面 → 上下翻 |
| 关于 y 轴翻折 | y = f(−x) | 左右翻转 | 负号在里面 → 左右翻 |
| 下翻上 | y = \|f(x)\| | x 轴下方部分翻到上方 | 整体加绝对值 |
| 右翻左 | y = f(\|x\|) | 保留 y 轴右侧，再左右镜像 | 只给 x 加绝对值 |

> **为什么横向变换总是和直觉相反？**
> 因为横向变换作用在**自变量**上。要让 `f(·)` 的括号里等于原来那个值，x 就必须「反着来」：
> `f(x+2)` 要向左移 2（x 变小 2）；`f(2x)` 要压缩一半（x 只需原来的一半）。
> **一句话：横向变换是「反着来」的。**
