## 一、图上其实只有三样东西

不管定义写得多长，图上就是：

1. 一条**横带**（高度 2ε，围绕水平线 y = A）
2. 一条**竖带**（宽度 2δ，围绕竖线 x = x₀）
3. 竖带里夹着的那**一小段曲线**

定义要说的全部内容就是：**第 3 样东西，整段都在第 1 样东西里面。**

---

## 二、逐符号翻译表

| 符号 | 念法 | 图上的东西 | 卡人的地方 |
| --- | --- | --- | --- |
| `ε` | epsilon | 横带**高度的一半** | 管**纵轴**方向，量的是函数值与 A 的偏差 |
| `δ` | delta | 竖带**宽度的一半** | 管**横轴**方向，量的是自变量与 x₀ 的距离 |
| `\|x − x₀\|` | x 到 x₀ 的距离 | 横轴上的一段长度 | 是**距离**不是坐标，天生 ≥ 0 |
| `0 < \|x − x₀\|` | 距离严格大于 0 | 竖带正中间被**挖掉**一条线 | 唯一的任务是排除 x = x₀（去心） |
| `\|f(x) − A\|` | 函数值到 A 的距离 | 竖直的一段长度 | 同样量距离，天生 ≥ 0 |
| `\|f(x) − A\| < ε` | 离 A 不足 ε | 函数值落在**横带**里 | 等价于 A − ε < f(x) < A + ε |
| `∀ε > 0` | 对任意正数 ε | 「你随便挑一个高度」 | 是**对方**出的题，可以任意小 |
| `∃δ > 0` | 存在正数 δ | 「我能找到一个宽度」 | 是**我方**给的答案，依赖 ε |
| `lim f(x) = A` | 极限存在 | 上面几件事**同时成立** | 不等于「f(x₀) = A」 |

---

## 三、把整句话念成人话

**符号版**

> ∀ε > 0，∃δ > 0，当 0 < |x − x₀| < δ 时，有 |f(x) − A| < ε

**逐段直译版**

> 不管你给多刁的 ε → 我都能找到一个 δ → 只要 x 离 x₀ 比 δ 还近（又不等于 x₀）→ 它的函数值就离 A 比 ε 还近

**一口气版**

> 不管把横带压得多窄，只要竖带取得够窄，竖带里那段曲线就整个落在横带里。

---

## 四、三个动作的先后顺序（定义的真正难点）

| 顺序 | 动作 | 谁说了算 |
| --- | --- | --- |
| ① | 任给 ε > 0 | **对方**：横带压多窄由他定 |
| ② | 据此找到 δ > 0 | **我方**：按这个 ε 反推竖带宽度 |
| ③ | 检验竖带内的曲线是否整段进横带 | 双方一起看图上结果 |

**关键**：δ 是**照着 ε 找出来的**。ε 换一个值，δ 就得重新找一遍。

所以写证明时的正确语序是：

> 「任给 ε > 0 ……，取 δ = ……，则当 0 < |x − x₀| < δ 时，有 ……」

顺序反过来写就是错的——先给一个固定的 δ，再要求所有 ε 都满足，那是另一个（强得多的）命题。

---

## 五、读图自查三步

拿到一条曲线问「在 x₀ 处极限是不是 A」，就依次问三句：

1. **横带在哪？** —— A 是多少，ε 给了多少
2. **竖带在哪？** —— x₀ 是多少，δ 是多少
3. **竖带里那段曲线，有没有露出横带？** —— 露了就不成立；没露，就还能再说

---

## 六、常见误解

| 误解 | 实际情况 |
| --- | --- |
| lim f(x) = A 就要求 f(x₀) = A | **不要求**。x₀ 处可以没有定义，所以图上画的是**空心点** |
| ε 是「一个很小的数」 | ε 是**任意**正数，可大可小，重点是「任意」 |
| 找到一个 δ 就一劳永逸 | δ 是跟着 ε 走的；ε 变小，δ 通常也得变小 |
| 整条曲线都要在横带里 | 只要求**竖带内**那一小段在横带里，竖带外一概不管 |
