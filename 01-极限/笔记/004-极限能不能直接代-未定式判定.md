## 一、一句话结论

> **极限值只有三种**：`0`、**非零常数 c**、`±∞`。
> **运算只有五种**：`+`、`−`、`×`、`÷`、`^`。
> 两两穷举 = 45 种组合，其中**只有 7 种不能直接算**——这 7 种就是未定式。

所以「敢不敢直接代」不是一个需要凭感觉判断的问题，而是**查表**的问题。

---

## 二、为什么会有未定式：0 和 ∞ 是对抗双方

「未定」= 光看两部分的极限值，**推不出**结果的极限值，还要看具体函数谁跑得快。

### 最有说服力的反例：三个不同的 `0 · ∞`

当 `x → 0⁺` 时，下面三组都是「→0 的量」乘「→∞ 的量」，形式完全一样：

| 组 | A | B | A · B | x→0⁺ 时的结果 |
| --- | --- | --- | --- | --- |
| 1 | `x` → 0 | `1/x` → ∞ | `x · (1/x)` | **1** |
| 2 | `x` → 0 | `1/x²` → ∞ | `x · (1/x²) = 1/x` | **+∞** |
| 3 | `x²` → 0 | `1/x` → ∞ | `x² · (1/x) = x` | **0** |

同一个 `0 · ∞`，三种答案。这就是「不定」的确切含义。**（可在交互页上拖动滑块亲眼看到三组数值分道扬镳）**

### 同理，`∞ − ∞` 也不定

| 表达式 | x→+∞ 时的结果 |
| --- | --- |
| `x² − x` | +∞ |
| `x − x²` | −∞ |
| `(x + 1) − x` | 1 |

### 所以规律是

| 情形 | 是否未定 |
| --- | --- |
| 运算中**不含 0、也不含 ∞**（常数与常数） | ✅ 一定可以直接算 |
| 运算中有 0 或 ∞，但**方向一致**（0+0、∞+∞、c×∞） | ✅ 可以直接算 |
| 运算中有 0 或 ∞，且**方向对抗** | ⚠️ 未定式 |

**0 是「压缩」，∞ 是「膨胀」。** 一个要压、一个要胀，谁赢不知道——这就是未定式的全部来源。

## 三、七个未定式总表（必须背下来）

| 未定式 | 谁和谁对抗 | 直觉解释 | 处理手段 |
| --- | --- | --- | --- |
| `0 / 0` | 0 与 0 | 分子分母都在缩，比值看谁缩得快 | 因式分解约分、等价无穷小替换、洛必达、泰勒展开 |
| `∞ / ∞` | ∞ 与 ∞ | 分子分母都在胀，比值看谁胀得快 | 抓大头（同除最高次幂）、洛必达 |
| `0 · ∞` | 0 与 ∞ | 一边压一边胀 | 变形为 `0/(1/∞)` 或 `∞/(1/0)`，化成上面两种 |
| `∞ − ∞` | 两个**同号** ∞ | 差多少取决于谁更大 | 通分、有理化、提公因子 |
| `1^∞` | 底数→1 与 指数→∞ | 底数那点偏差被无穷次方放大 | 凑第二重要极限，或写成 `e^(∞·ln 1)` |
| `0^0` | 0 与 0 | 底数缩、指数也缩 | 取对数，化成 `0 · ∞` |
| `∞^0` | ∞ 与 0 | 爆掉又被 0 次方压平 | 取对数，化成 `0 · ∞` |

> **记忆锚点**：七个全部涉及 `0` 或 `∞`。一个不涉及 0/∞ 的四则运算，永远不需要担心。

## 四、五张判定表（穷举）

### 1. 加法 `A + B`

| A + B | B→0 | B→c | B→∞ |
| --- | --- | --- | --- |
| **A→0** | 0 | c | ∞ |
| **A→c** | c | c | ∞ |
| **A→∞** | ∞ | ∞ | ⚠️ 同号→∞，**异号 = ∞−∞ 未定** |

### 2. 减法 `A − B`

| A − B | B→0 | B→c | B→∞ |
| --- | --- | --- | --- |
| **A→0** | 0 | −c | −∞ |
| **A→c** | c | **0** | −∞ |
| **A→∞** | ∞ | ∞ | ⚠️ **同号 = ∞−∞ 未定**，异号→∞ |

> 注意 `c − c = 0` 是**可以直接算的**，别习惯性当未定式。

### 3. 乘法 `A · B`

| A · B | B→0 | B→c | B→∞ |
| --- | --- | --- | --- |
| **A→0** | 0 | 0 | ⚠️ **0 · ∞ 未定** |
| **A→c** | 0 | c′ | ∞ |
| **A→∞** | ⚠️ **0 · ∞ 未定** | ∞ | ∞ |

> **例 1-2 走的就是这张表**：`c · ∞`（绿）→ `∞ · ∞`（绿），全程没踩红格。

### 4. 除法 `A / B`

| A / B | B→0 | B→c | B→∞ |
| --- | --- | --- | --- |
| **A→0** | ⚠️ **0/0 未定** | 0 | 0 |
| **A→c** | ∞ | c′ | 0 |
| **A→∞** | ∞ | ∞ | ⚠️ **∞/∞ 未定** |

> 两个「看着危险其实很安全」的格子：`0 / c = 0`、`c / 0 = ∞`，都能直接算。

### 5. 乘方 `A^B`（底数取正值）

| A^B | B→0 | B→c | B→∞ |
| --- | --- | --- | --- |
| **A→0⁺** | ⚠️ **0⁰ 未定** | c>0→0；c<0→∞ | 0 |
| **A→1** | 1 | 1 | ⚠️ **1^∞ 未定** |
| **A→c（c>0，c≠1）** | 1 | c^c | c>1→∞；0<c<1→0 |
| **A→+∞** | ⚠️ **∞⁰ 未定** | c>0→∞；c<0→0 | ∞ |

## 五、`恒等于` 和 `趋于` 是两回事（最容易混）

| 写法 | 含义 | 结果 |
| --- | --- | --- |
| `1^∞` | 底数**趋于** 1（但每一点都不等于 1），指数趋于 ∞ | ⚠️ **未定**。例：`(1 + 1/x)^x → e`，`(1 + 2/x)^x → e²` |
| `1^c` | 底数趋于 1，指数趋于普通常数 | = 1，直接算 |
| **底数恒为 1** 的无穷次方 | 真的是 `1 × 1 × 1 × …` | = 1，直接算 |
| `0 / 0` | 分子分母都**趋于** 0 | ⚠️ **未定** |
| **分子恒为 0**，分母趋于 c ≠ 0 | `0 / c` | = 0，直接算 |

**关键**：`1^∞` 之所以不定，是因为底数不是 1，而是「1 加上一个无限小的偏差」。无穷次方会把这点偏差放大到任何值——这就是第二重要极限 `e` 的来源。

---

## 六、做题心智流程（三步）

1. **定位**：把式子的每一部分单独求极限，各写成一个符号（`0` / `c` / `∞`）。
2. **对照**：按运算符查上面对应的表。
   - 全绿 → 结束，直接写答案（符号自己判）。
   - 出现红格 → 进第 3 步。
3. **变形**：按「七个未定式总表」里那一列的手段处理，**目标是把这个红格变成绿格**（通常是化归成 `0/0` 或 `∞/∞` 再上洛必达 / 等价替换）。

> ⚠️ **不要一上来就洛必达**。洛必达只对 `0/0` 和 `∞/∞` 两种形态合法，套在别的地方会直接算错。

## 七、用这套流程回看例 1-2

题目：`lim(x→−∞) (arctan x) · e^(−x) · x`

| 因子 | 极限值 | 归类 |
| --- | --- | --- |
| `arctan x` | `−π/2 ≈ −1.5708` | `c`（非零常数） |
| `e^(−x)` | `+∞` | `∞` |
| `x` | `−∞` | `∞` |

运算只有乘法，查**乘法表**：

- `c · ∞` → 第 2 行第 3 列 → 绿色，结果 `∞`
- `∞ · ∞` → 第 3 行第 3 列 → 绿色，结果 `∞`

**两次都踩绿格 ⇒ 直接乘合法。** 剩下的只是判符号：`(−)·(+)·(−) = +`，故 `+∞`。

**反例对比**：若原题是 `lim(x→0) (arctan x) · (1/x)`，则变成 `0 · ∞`——踩红格，必须先变形成 `arctan x / x → 1` 才能算。

## 八、口诀

> **先定位 → 再对照 → 最后才谈手段。**
> 绿格直接写，红格才变形。
> 七个未定式，全部起源于 `0` 和 `∞` 的对抗。

## 九、自测（判断是否未定式，先别算）

1. `lim(x→∞) x² · e^(−x)`
2. `lim(x→0) x · ln x`
3. `lim(x→∞) (x² + 1) / x`
4. `lim(x→0) sin x / x`
5. `lim(x→∞) (1 + 2/x)^x`
6. `lim(x→0⁺) x^x`
7. `lim(x→∞) (√(x²+x) − x)`
8. `lim(x→0) (1/x) · (2x)`
9. `lim(x→∞) (x + 1/x)`

<details>
<summary>答案（点开）</summary>

| # | 形式 | 是否未定 | 结果 |
| --- | --- | --- | --- |
| 1 | `∞ · 0` | ⚠️ 是 | 0（洛必达或抓大头：`x²/e^x → 0`） |
| 2 | `0 · (−∞)` | ⚠️ 是 | 0（`x ln x → 0`，经典结论） |
| 3 | `∞ / ∞` | ⚠️ 是 | ∞（抓大头：`≈ x → ∞`） |
| 4 | `0 / 0` | ⚠️ 是 | 1（第一重要极限） |
| 5 | `1^∞` | ⚠️ 是 | `e²` |
| 6 | `0⁰` | ⚠️ 是 | 1 |
| 7 | `∞ − ∞` | ⚠️ 是 | `1/2`（分子有理化） |
| 8 | `∞ · 0` 形式，但**能约分** | 否 | 先约掉 x：`= 2`，**直接算** |
| 9 | `∞ + 0` | 否 | ∞，**直接算** |

> 第 8、9 题是重点：**看着像未定式，其实不是**。第 8 题约分后就是常数 2；第 9 题是「∞ + 趋于 0」的确定型。
> 判断未定式要看**化简后的真实形式**，不是看表面有没有出现 0 或 ∞。
