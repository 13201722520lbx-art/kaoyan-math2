## 一、单位圆：一切特殊值的源头

设角 θ 的终边与单位圆交于 $(x_0, y_0)$，则

$$x_0 = \cos\theta,\qquad y_0 = \sin\theta,\qquad \tan\theta = \frac{y_0}{x_0}$$

**只需背第一象限 5 个角**（sin 的值写成 $\sqrt{n}/2$，n 依次取 0,1,2,3,4）：

| θ | 0 | π/6 | π/4 | π/3 | π/2 |
| --- | --- | --- | --- | --- | --- |
| **sin θ** | 0 | 1/2 | √2/2 | √3/2 | 1 |
| **cos θ** | 1 | √3/2 | √2/2 | 1/2 | 0 |
| **tan θ** | 0 | √3/3 | 1 | √3 | 不存在 |

> cos 一列就是把 sin 倒着数。其他象限用 **奇变偶不变，符号看象限**。

## 二、反三角函数（本次的复习重点）

### 1. 四个值域区间（最重要，错了全错）

| 函数 | 定义域 | 值域 | 端点 | 奇偶 | 导数 |
| --- | --- | --- | --- | --- | --- |
| arcsin x | [−1, 1] | **[−π/2, π/2]** | 取得到 | 奇 | 1/√(1−x²) |
| arccos x | [−1, 1] | **[0, π]** | 取得到 | 非奇非偶 | −1/√(1−x²) |
| arctan x | ℝ | **(−π/2, π/2)** | **取不到** | 奇 | 1/(1+x²) |
| arccot x | ℝ | **(0, π)** | **取不到** | 非奇非偶 | −1/(1+x²) |

**这张表的核心信息**：arcsin / arccos 是闭区间（端点取得到），arctan / arccot 是开区间（端点永远取不到）。

所以只能写 $\lim_{x\to+\infty}\arctan x = \dfrac{\pi}{2}$，**绝不能写** $\arctan(+\infty) = \dfrac{\pi}{2}$。

### 2. 特殊值

| x | −1 | −√3/2 | −√2/2 | −1/2 | 0 | 1/2 | √2/2 | √3/2 | 1 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **arcsin x** | −π/2 | −π/3 | −π/4 | −π/6 | 0 | π/6 | π/4 | π/3 | π/2 |
| **arccos x** | π | 5π/6 | 3π/4 | 2π/3 | π/2 | π/3 | π/4 | π/6 | 0 |

| x | −√3 | −1 | −√3/3 | 0 | √3/3 | 1 | √3 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **arctan x** | −π/3 | −π/4 | −π/6 | 0 | π/6 | π/4 | π/3 |
| **arccot x** | 5π/6 | 3π/4 | 2π/3 | π/2 | π/3 | π/4 | π/6 |

> 记忆钩子：arcsin 与 arccos **同一列相加恒为 π/2**；arctan 一行的值都是 π/6、π/4、π/3 这类「常见角」。

### 3. 必背恒等式

| 恒等式 | 注意 |
| --- | --- |
| arcsin x + arccos x = π/2 | x ∈ [−1, 1] |
| arctan x + arccot x = π/2 | x ∈ ℝ |
| **arctan x + arctan(1/x) = π/2（x>0）；= −π/2（x<0）** | **易错重灾区，符号必须分情况** |
| arccos(−x) = π − arccos x | arccos 不是奇函数 |
| arcsin(−x) = −arcsin x，arctan(−x) = −arctan x | 这两个是奇函数 |
| arctan x + arctan y = arctan[(x+y)/(1−xy)] | 结果须落在 (−π/2, π/2) 内，否则 ±π 修正 |
| 2 arctan x = arctan[2x/(1−x²)] | \|x\| < 1 |

### 4. 相关极限（高频）

- `lim(x→+∞) arctan x = π/2`；`lim(x→−∞) arctan x = −π/2`
- `arctan x ~ x`、`arcsin x ~ x`（x → 0）
- `lim(x→+∞) arctan(1/x) = 0`，但 `lim(x→0⁺) arctan(1/x) = π/2` —— 别混

## 三、三角恒等式（按用途索引）

| 场景 | 用哪条 |
| --- | --- |
| 化简根号、凑平方 | sin²x + cos²x = 1 |
| 把任意角化到第一象限 | 诱导公式（奇变偶不变，符号看象限） |
| 拆角、凑角 | 和差角公式 |
| **积分里降次** | sin²x = (1−cos2x)/2，cos²x = (1+cos2x)/2 |
| 分子出现同频差 | 和差化积（差 → 积） |
| 积分里把乘积拆开 | 积化和差 |
| 三角有理式兜底 | 万能代换 t = tan(x/2) |

## 四、指数与对数

| 公式 | 说明 |
| --- | --- |
| ln(ab) = ln a + ln b；ln(a/b) = ln a − ln b | 乘除 → 加减 |
| ln(aⁿ) = n·ln a | 把指数拉下来（**处理幂指函数必用**） |
| logₐb = ln b / ln a | 换底，统一到 e |
| **aˣ = e^(x·ln a)** | **求导/积分遇到 aˣ 的第一步** |
| e^(ln x) = x；ln(eˣ) = x | 互逆消去 |
| y = u^v ⟹ ln y = v·ln u | 对数求导法 |

**常用数值**：e ≈ 2.718、e² ≈ 7.389、1/e ≈ 0.368、ln2 ≈ 0.693、ln3 ≈ 1.099、ln10 ≈ 2.303

**增长阶**（x → +∞）：`ln x ≪ x^a ≪ aˣ ≪ xˣ`

## 五、代数变换四板斧

| 板斧 | 公式 | 治什么 |
| --- | --- | --- |
| **有理化** | √a − √b = (a−b)/(√a+√b) | 带根号的 0/0、∞−∞ |
| **因式分解** | xⁿ − aⁿ = (x−a)(xⁿ⁻¹ + xⁿ⁻²a + … + aⁿ⁻¹) | 约掉零因子 |
| **通分** | 1/a − 1/b = (b−a)/(ab) | ∞ − ∞ |
| **提取最大项** | x² + 3x = x²(1 + 3/x) | ∞/∞ |

## 六、极限计算的固定顺序（做题时按这个走）

1. **先代入** —— 定式直接出答案，未定式才继续（最容易被跳过）
2. **约分 / 有理化 / 通分** —— 处理 0/0、∞−∞
3. **等价无穷小替换** —— 只替换**乘除因子**
4. **洛必达** —— 只对 0/0 与 ∞/∞
5. **泰勒展开** —— 前面都不行时，展开到分子分母最低次幂相同

**幂指型三种未定式（1^∞、0⁰、∞⁰）统一套路**：取对数 → 指数提前 → 变成 0·∞。

## 七、这次的三个「别搞错」

1. `arctan x + arctan(1/x)` 的值**依赖 x 的符号**（+π/2 或 −π/2）。
2. `arctan` 的 π/2 **取不到**，只能无限逼近。
3. `lim(x→−∞) arctan x = −π/2`，不是 π/2。
