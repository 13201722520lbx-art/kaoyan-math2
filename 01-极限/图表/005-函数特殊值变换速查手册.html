一、四个反三角函数的「住处」

函数定义域值域（必须背）奇偶性单调性导数
arcsin x[−1, 1][−π/2, π/2]　闭奇函数递增1/√(1 − x²)
arccos x[−1, 1][0, π]　闭非奇非偶递减−1/√(1 − x²)
arctan x(−∞, +∞)(−π/2, π/2)　开奇函数递增1/(1 + x²)
arccot x(−∞, +∞)(0, π)　开非奇非偶递减−1/(1 + x²)
关键区别：arcsin / arccos 的端点取得到；arctan / arccot 的端点 ±π/2 和 0、π 永远取不到。所以写的是 lim(x→+∞) arctan x = π/2，而绝不能写 arctan(+∞) = π/2。

三、增长阶（x → +∞ 时谁跑得快）

ln x　≪　x^a (a > 0)　≪　aˣ (a > 1)　≪　xˣ

例：lim(x→+∞) (ln x)/x = 0，lim(x→+∞) x/eˣ = 0。分子跑得慢就是 0，跑得快就是 ∞。

常用结论：lim(x→+∞) xⁿ/eˣ = 0（任何 n）、lim(x→0⁺) x·ln x = 0、lim(x→+∞) (ln x)/x^a = 0。这三条在 ∞/∞ 型里能直接省掉洛必达。

一、代数变换四板斧

板斧怎么做治什么
有理化√a − √b = (a − b)/(√a + √b)
(分子分母同乘共轭式)		带根号的 0/0 型、∞ − ∞ 型
因式分解x² − a² = (x − a)(x + a)
x³ − a³ = (x − a)(x² + ax + a²)
x³ + a³ = (x + a)(x² − ax + a²)
xⁿ − aⁿ = (x − a)(xⁿ⁻¹ + xⁿ⁻²a + … + aⁿ⁻¹)		0/0 型，约掉零因子

提取最大项x² + 3x = x²(1 + 3/x)∞/∞ 型，上下同除最高次幂
换元倒代令 t = 1/x，则 x→∞ ⟺ t→0把 x→∞ 的题变回 x→0

三、极限计算固定顺序

  • ① 先代入 —— 是定式就直接出答案；是未定式才继续。这一步最容易被跳过，也最容易白算。
  • ② 能约就约、能有理化就有理化 —— 处理 0/0 型。
  • ③ 通分 / 提取最大项 —— 处理 ∞ − ∞、∞/∞ 型。
  • ④ 等价无穷小替换 —— 只替换乘除因子，能一秒出答案就别上洛必达。
  • ⑤ 洛必达 —— 只对 0/0 和 ∞/∞ 用；用之前先确认是这两种型。
  • ⑥ 泰勒展开 —— 前面都不行时的终极手段，展开到「分子分母最低次幂相同」为止。
