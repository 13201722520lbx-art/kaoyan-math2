例 1-2 最后一步 · 三因子符号分解器

题目：limx→−∞ (arctan x) · e−x · x。 讲义最后那一步 (−π/2)·(+∞)·(−∞) = +∞ 不是算出来的，是判符号判出来的 —— 把三个因子各自的去向确定下来，符号一乘，结论就出来了。

① 先看左边：arctan x 到底趋向谁

这是整题最容易翻车的一步。很多人心里默认 arctan 都是往 +π/2 跑，忽略了方向。

左图：y = arctan x。值域被锁死在 (−π/2, π/2) 里，x 往左走到 −∞，曲线从上方贴住水平线 y = −π/2，永远碰不到。

右图：整个乘积 f(x) = arctan x · e−x · x 的走势（纵轴是 log₁₀，否则数值太大画不下）。x 越负，它一路往上冲。

③ 三个因子各自的去向（固定结论）

x → −∞因子趋向是常数还是无穷符号
第 1 个arctan x−π/2 ≈ −1.5708非零有限常数−
第 2 个e−x+∞（指数爆炸）无穷大+
第 3 个x−∞无穷大−

合法性来自哪里？ 有限个因子的乘积，只要每个因子的极限都存在（有限数或定号的无穷大），就可以把极限分别算完再相乘。这里三个因子都「有确定去向」，且没有出现 0·∞，所以直接相乘是被允许的。

xarctan xe−xx乘积

乘积列从 2 一路涨到 7 千万，且始终为正——这就是「→ +∞」的直接证据。

④ 三个常见的坑

  • 坑 1：arctan x 的符号。 x → +∞ 时它才是 +π/2；x → −∞ 时是 −π/2。这里差一个负号，最终答案就完全反了（会得到 −∞）。
  • 坑 2：把 (+∞)·(−∞) 当成未定式。 它不是。∞·∞ 永远是 ∞，只不过要判符号：负 × 负 = 正，所以是 +∞。
  • 坑 3：只写「= ∞」。 数二里无穷大的比较必须带符号，因为 +∞ 和 −∞ 在后续（比如极限存在性、渐近线、间断点分类）里是两回事。
口诀：碰到「常数 × 无穷 × 无穷」，别急着套洛必达。先做两件事——定位（每个因子各自去哪）、定号（乘起来是正是负）。只要不出现 0·∞、∞−∞、0/0，答案当场就出来了，一行写完。

⑤ 一句话总结这一步

arctan x → −π/2（负常数）
e−x → +∞（正无穷）
x → −∞（负无穷）
── 乘积符号 = (−)·(+)·(−) = +，量级是无穷 ⇒ +∞
