极限能不能直接代？· 五张判定表

你的直觉是对的：麻烦只来自 0 和 ∞。极限值一共只有三种——0、非零常数 c、±∞； 运算一共只有五种——加减乘除和乘方。把这些组合穷举出来，45 格里只有 7 格不能直接算，这 7 格就是未定式。

① 先搞清楚：「未定」到底是什么意思

「未定」不是说算不出来，而是说 光看两部分的极限值，推不出结果的极限值——还要看具体函数「谁跑得快」。

最典型的就是 0 · ∞。下面三组乘积，在 x → 0⁺ 时形式完全一样（都是「→0 的量」乘「→∞ 的量」），结果却完全不同：

x = 0.001 ← 往右拖，让 x 更接近 0
x · (1/x)
1
x · (1/x²)
1000
x² · (1/x)
0.001

条形长度是 log₁₀ 刻度，中线代表「值 = 1」。三组的 A → 0、B → ∞ 都成立，但 A·B 分别稳定在 1、→ +∞、→ 0。 同一个 0·∞，三种答案——这就是「未定式」的确切含义。

② 七个未定式，一个也不能少

未定式谁和谁在打架为什么不定（直觉）标准处理手段
0 / 00 与 0分子分母都在变小，比值取决于谁跑得快因式分解约分 / 等价无穷小 / 洛必达 / 泰勒
∞ / ∞∞ 与 ∞分子分母都在变大，比值取决于增长速度之比抓大头（同除最高次幂）/ 洛必达
0 · ∞0 与 ∞一个要往下压、一个要往上顶变形为 0/(1/∞) 或 ∞/(1/0)，转成上面两种
∞ − ∞两个同号 ∞两个都在变大，差的量级取决于哪边更大通分 / 有理化（分子有理化）/ 提公因子
1∞底数 →1 与指数 →∞底数只要不严格等于 1，无穷次方就能放大出任何值凑第二重要极限 (1+1/u)^u → e，或 u^v = e^(v·ln u)
000 与 0底数往 0 缩、指数往 0 缩，两边拉锯取对数：e^(0·ln 0) → 转成 0·∞
∞0∞ 与 0底数爆掉又被 0 次方拉平取对数：e^(0·ln ∞) → 转成 0·∞
看出规律了吗：七个未定式里，每一个都是「0 或 ∞ 参与的对抗」。 0 是「压缩」，∞ 是「膨胀」，两者方向相反时结果就不确定。 反过来，凡是不含 0 也不含 ∞ 的运算（常数 + 常数、常数 × 常数、非零常数 ÷ 常数），一定可以直接算。

④ 回到例 1-2：为什么它敢直接乘

原题 lim (arctan x)·e^(−x)·x，把三因子按类型归类：

因子类型对应表里的符号
arctan x收敛到 −π/2 ≈ −1.5708c（非零常数）
e^(−x)→ +∞∞
x→ −∞∞

只看乘法表（点上面的「乘法 A · B」）：

  • c · ∞ 落在第 2 行第 3 列 → 绿格，可以算，结果是 ∞
  • ∞ · ∞ 落在第 3 行第 3 列 → 绿格，可以算，结果是 ∞
两次乘法都踩在绿格上，一次红格都没碰到 ⇒ 直接乘是合法的。
所以 (−π/2)·(+∞)·(−∞) 一路算下来，只剩符号要自己判：负 × 正 × 负 = 正 ⇒ +∞。

对比一下：如果原题是 lim(x→0) (arctan x) · (1/x)，那就变成 0 · ∞——踩红格了，必须变形（化成 arctan x / x → 1）才能算。

⑤ 做题时的心智流程

  1. 代入：把每一部分单独求极限，写成一个符号（0 / c / ∞）。
  2. 对照：按运算符查上面对应的表。绿→ 结束，直接写答案；红→ 进第 3 步。
  3. 变形：按「七个未定式总表」里那一列的手段处理，目标是把红格变成绿格（通常是化归成 0/0 或 ∞/∞ 再上洛必达 / 等价替换）。
口诀：先定位（每部分去哪）→ 再对照（绿格直接写，红格要变形）→ 最后才谈手段。
不要一上来就洛必达——洛必达只对 0/0 和 ∞/∞ 两种形态合法，用在别处会直接算错。

⑥ 一个特别容易混的点

写法含义能不能直接算
1∞底数趋于 1（但每一点都不是 1），指数趋于 ∞未定式。例：(1+1/x)^x → e
1c底数趋于 1，指数趋于普通常数 c可直接算，= 1
0 / 0分子分母都趋于 0未定式
0 / c分子趋于 0，分母趋于非零常数可直接算，= 0
c / 0分子趋于非零常数，分母趋于 0可直接算，= ∞（符号看两侧）

关键区分：「恒等于」和「趋于」是两回事。恒等于 1 的底数的 ∞ 次方确实是 1；但趋于 1 的底数不是——它总有那么一点点偏差，无穷次方会把这点偏差放大到任何值。
