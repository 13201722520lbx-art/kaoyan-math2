五大类初等函数 · 快速回忆复习地图

两三年没碰数学，忘掉的大概率不是「怎么算」，而是图像的形状和谁是谁的反函数。 这个页面按你列的五类组织，每一类都配一张能拖动的图：拖参数看图像怎么变，比看静态图记得牢。

先看全局：这五类是怎么串起来的

五类基本初等函数不是并列的五个孤立事物，它们之间有两条「互为反函数」的通道，这是最容易忘、也最该记住的结构。

五类速查卡

幂函数　y = x^a

定义域 / 值域：随 a 而定
恒过：a>0 → (0,0) 和 (1,1)；a<0 → 只过 (1,1)
特征：a>0 时在 (0,+∞) 单调增
  • a 为正整数 → 多项式型
  • a 为负数 → 双曲线型，有渐近线
  • a 为分数 → 根式型，注意定义域

指数函数　y = a^x

定义域 ℝ；值域 (0, +∞)
恒过：(0, 1)　—— 无论 a 是多少
单调：a>1 增；0<a<1 减
  • x 轴（y=0）是水平渐近线，永远碰不到
  • a^x 永远 > 0

对数函数　y = logₐx

定义域 (0, +∞)；值域 ℝ
恒过：(1, 0)　—— 无论 a 是多少
单调：a>1 增；0<a<1 减
  • y 轴（x=0）是垂直渐近线
  • 是 a^x 的反函数，图像关于 y=x 对称

三角函数　sin / cos / tan

sin, cos：定义域 ℝ，值域 [−1, 1]
tan：定义域 x ≠ π/2 + kπ，值域 ℝ
周期：sin/cos 为 2π；tan 为 π
  • sin 奇函数，cos 偶函数，tan 奇函数
  • tan 有垂直渐近线 x = π/2 + kπ

反三角函数　arcsin / arccos / arctan

arcsin：定义域 [−1,1]，值域 [−π/2, π/2]
arccos：定义域 [−1,1]，值域 [0, π]
arctan：定义域 ℝ，值域 (−π/2, π/2)
  • 关键：arcsin/arccos 是闭区间，arctan 是开区间
  • 所以 arctan 的水平渐近线永远取不到

反函数关系

判定：f 是一一映射 ⟺ 存在反函数
充分条件：f 严格单调
对称：y=f(x) 与 y=f⁻¹(x) 关于 y = x 对称
  • f⁻¹(f(x)) = x　且　f(f⁻¹(x)) = x
  • 互反函数：定义域与值域互换

对数运算律

公式白话
logₐ(MN) = logₐM + logₐN积 → 和（这是对数被发明的理由：把乘法变成加法）
logₐ(M/N) = logₐM − logₐN商 → 差
logₐ(M^n) = n · logₐM把指数拉下来（处理幂指函数必用）
logₐ1 = 0；logₐa = 1两个基本值
logₐb = ln b / ln a换底公式，统一到 e
a^(logₐN) = N指数与对数互相抵消
增长阶（x → +∞，非常重要）：ln x ≪ x^a ≪ a^x ≪ x^x
念法：「对数最慢，幂函数中间，指数最快」。做 ∞/∞ 抓大头时全靠这个。

反函数：把「输入输出」调个头

函数 y = f(x) 是说「给 x，算出 y」。反函数 y = f⁻¹(x) 是反过来：「给 y，问原来是哪个 x」。 几何上就是把这个点沿 y = x 翻折过去。

点 P 的横坐标 a = 1.5 纵坐标 b = 1.4

拖动两个滑块，P(a, b) 和它的镜像 P′(b, a) 始终关于 y = x 对称。这就是「反函数图像关于 y=x 对称」的全部含义。

三个必记性质

  • 存在性：函数有反函数 ⟺ 它是一一映射（每个 y 只对应一个 x）。严格单调是保证一一映射的充分条件。
  • 定义域值域互换：f⁻¹ 的定义域 = f 的值域；f⁻¹ 的值域 = f 的定义域。
  • 互逆抵消：f⁻¹(f(x)) = x（x 在 f 的定义域内）；f(f⁻¹(x)) = x（x 在 f⁻¹ 的定义域内）。

反三角函数：定义域被「切一刀」的产物

sin、cos、tan 都是周期的，本来没有反函数。为了让它们有反函数，数学上把定义域限制在一个单调区间里，这就是「主值分支」。

函数定义域值域（主值区间）端点奇偶性
y = arcsin x[−1, 1][−π/2, π/2]取得到奇函数
y = arccos x[−1, 1][0, π]取得到非奇非偶
y = arctan xℝ(−π/2, π/2)取不到奇函数
这张表最重要的信息：arcsin / arccos 是闭区间（端点能取到），arctan 是开区间（端点永远取不到）。
所以只能写 lim(x→+∞) arctan x = π/2，绝不能写 arctan(+∞) = π/2——这正是例 1-2 里那个 −π/2 的来源。

指对互换：一个等式，两个方向

这是最容易忘、但复习一遍就能捡回来的一组关系。核心只有一句话：

ab = N　　⟺　　logaN = b
「a 的 b 次方等于 N」和「以 a 为底 N 的对数是 b」说的是同一件事
指数形式对数形式说明
2³ = 8log₂8 = 3底数 2 不变，3 和 8 换位置
10² = 100lg 100 = 2lg 表示以 10 为底
e⁰ = 1ln 1 = 0ln 表示以 e 为底
a^(logₐN) = Nlogₐ(a^b) = b两者互相抵消，回到原样
e^(ln x) = x　(x>0)ln(e^x) = x最常用的两个特例
口诀：底数不动，指数与真数换位。
a^b = N 里的 b（指数）搬到等号右边就变成 log 的结果；N 从右边搬到真数位置。

变换口诀表

变换写法图像怎么动记忆口诀
纵向平移y = f(x) + cc > 0 向上移 c，c < 0 向下移 |c|上加下减
横向平移y = f(x + b)b > 0 向左移 b，b < 0 向右移 |b|左加右减（与直觉相反！）
纵向伸缩y = A · f(x)|A| > 1 纵向拉伸，|A| < 1 纵向压缩A 管高度
横向伸缩y = f(kx)k > 1 横向压缩到 1/k，0 < k < 1 横向拉伸k 管胖瘦，与直觉相反
关于 x 轴翻折y = −f(x)上下翻转负号在外面 → 上下翻
关于 y 轴翻折y = f(−x)左右翻转负号在里面 → 左右翻
加绝对值（下翻上）y = |f(x)|x 轴下方部分翻到上方整体加绝对值 → 下翻上
加绝对值（右翻左）y = f(|x|)保留 y 轴右侧，再左右镜像只给 x 加 → 右翻左
最容易记反的两个：
① f(x + 2) 是向左移，不是向右——因为要让括号里等于原来那个值，x 得变小。
② f(2x) 是横向压缩，不是拉伸——同理，x 只要原来的一半就能达到同样的效果。
共同原因：横向变换是「反着来」的。
