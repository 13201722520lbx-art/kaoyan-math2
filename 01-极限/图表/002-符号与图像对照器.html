符号 ↔ 图像 对照器：ε-δ 定义怎么读

讲义上只有符号，没有「这个符号在图上是哪块地方」。这一页把那层翻译补上：点上面的符号，图上对应的部分就会亮起来。

一、点着看：哪段符号对应图上哪块

整句一起看：竖带内的这段曲线，被横带整段兜住。

二、这句话其实只有三样东西

不管定义写得多长，图上就是：一条横带（高度 2ε，围绕 y = A）、一条竖带（宽度 2δ，围绕 x = x₀）、以及竖带里夹着的那一小段曲线。定义要说的全部内容就是——第 3 样东西整段都在第 1 样东西里面。

三、三个动作的先后顺序

δ 是照着 ε 找出来的。ε 换一个值，δ 就得重新找一遍。所以证明的正确语序是「任给 ε > 0 ……，取 δ = ……」；反过来先定死一个 δ 再要求所有 ε 都满足，那是另一个强得多的命题。

四、逐符号翻译表

符号念法图上的东西卡人的地方
εepsilon横带高度的一半管纵轴方向，量函数值与 A 的偏差
δdelta竖带宽度的一半管横轴方向，量自变量与 x₀ 的距离
|x − x₀|x 到 x₀ 的距离横轴上的一段长度是距离不是坐标，天生 ≥ 0
0 < |x − x₀|距离严格大于 0竖带正中间被挖掉一条线唯一作用是排除 x = x₀（去心）
|f(x) − A| < ε离 A 不足 ε函数值落在横带里等价于 A − ε < f(x) < A + ε
∀ε > 0对任意正数 ε「你随便挑一个高度」是对方出的题，可以任意小
∃δ > 0存在正数 δ「我能找到一个宽度」是我方给的答案，依赖 ε
lim f(x) = A极限存在上面几件事同时成立不等于「f(x₀) = A」

五、把整句话念成人话

不管你给多刁的 ε → 我都能找到一个 δ → 只要 x 离 x₀ 比 δ 还近（又不等于 x₀）→ 它的函数值就离 A 比 ε 还近

一口气版：不管把横带压得多窄，只要竖带取得够窄，竖带里那段曲线就整个落在横带里。

六、读图自查三步

  • 横带在哪？ A 是多少，ε 给了多少
  • 竖带在哪？ x₀ 是多少，δ 是多少
  • 竖带里那段曲线，有没有露出横带？ 露了就不成立；没露，就还能再说

七、常见误解

误解实际情况
lim f(x) = A 就要求 f(x₀) = A不要求。x₀ 处可以没有定义，所以图上画的是空心点
ε 是「一个很小的数」ε 是任意正数，可大可小，重点是「任意」
找到一个 δ 就一劳永逸δ 跟着 ε 走；ε 变小，δ 通常也得变小
整条曲线都要在横带里只要求竖带内那一小段在横带里，竖带外一概不管
