## 0. 一条主线：三条性质都是「ε 带 → δ 窗口」的推论

极限 lim_{x→x₀} f(x) = A 的定义可以这样读：

> 你随便画一条宽度为 2ε 的横带（A−ε 到 A+ε），我总能找到一个 δ，
> 使得在 **0 < |x−x₀| < δ** 内，曲线**完全**落在带子里。

两个关键词：

| 关键词 | 含义 |
| --- | --- |
| **局部** | 保证只在 x₀ 的一个**去心邻域**内有效，邻域外一概不管 |
| **任意 ε** | ε 想多小就多小；ε 越小，δ 通常越小 |

④⑤⑥ 就是这条机制的三个副产品。

---

## ① ④ 极限的有界性

**原文**：若 lim_{x→x₀} f(x) = A 且存在常数 M > 0，则在 x₀ 的「附近」有 |f(x)| ≤ M。

**证明（三行）**：

1. 取 ε = 1（随便取一个正数都行）；
2. 由定义，∃δ > 0，当 0 < |x−x₀| < δ 时有 |f(x) − A| < 1；
3. 于是 |f(x)| ≤ |A| + 1，**令 M = |A| + 1** 即可。

**要点**：M 依赖 A；δ 依赖 ε。所以正确说法是「**极限存在 ⇒ 局部有界**」。

**易错点**：

- 它只保证**局部**有界。反例：f(x) = 1/x 在 x₀ = 1 处局部有界，但在 (0,1) 上整体无界。
- 反过来不成立：**局部有界 ⇏ 极限存在**。反例：f(x) = sin(1/x) 在 x₀ = 0 处有界，但极限不存在（振荡）。
- 若 x₀ = 0 处 f(x) = 1/x，则极限不存在，也就谈不上这个结论——**前提是极限存在**。

---

## ② ⑤ 极限的保号性

### 正向：极限的符号 → 函数的符号

**原文**：若 lim f(x) = A > 0（< 0），则在 x₀ 的「附近」有 f(x) > 0（< 0）。

**证明**：取 **ε = A / 2**（关键就在这个取法，不是随便取）。

- 邻域内 |f(x) − A| < A/2
- ⇒ A/2 < f(x) < 3A/2
- ⇒ **f(x) > A/2 > 0**

**记忆**：把 ε 取成「A 到 0 的一半」，带子的下沿就顶在 A/2，稳稳压在 0 上方。

### 反向：函数的符号 → 极限的符号

**原文**：若 lim f(x) = A，且在 x₀ 的「附近」有 f(x) ≥ 0（或 f(x) > 0），则 lim f(x) ≥ 0。

**注意**：结论是 **A ≥ 0**，不是 A > 0。

**反例（严格号被磨平）**：f(x) = 2.5x²，x₀ = 0。

- 任意去心邻域内都有 f(x) > 0 ✓
- 但 lim_{x→0} 2.5x² = **0**，并不 > 0 ✗

**直觉**：函数值可以永远比 0 大一点点，但「一点点」越来越小，极限正好落在 0 上。

---

## ③ ⑥ 极限的不等式关系

**原文**：若 lim f = A，lim g = B，且 lim f > lim g（即 A > B）⇒ 在 x₀ 的「附近」有 f(x) > g(x)；
反之，若附近有 f(x) ≥ g(x)（或 f(x) > g(x)），则 lim f ≥ lim g。

**做法**：令 h(x) = f(x) − g(x)，于是

- 「f > g」⇔「h > 0」
- 「A > B」⇔「lim h > 0」

**直接把 ⑤ 搬过来**：

- 正向取 ε = (A − B)/2，得邻域内 h > 0，即 f > g；
- 反向只能得 lim h ≥ 0，即 **A ≥ B**。

**反例**：f(x) = 0.5 + 2.5x²，g(x) = 0.5。

- 任意去心邻域内 f(x) > g(x) ✓
- 但 lim f = lim g = 0.5，A = B，并不 A > B ✗

**另一层「局部」**：正向保证只在 x₀ 附近成立。曲线在远离 x₀ 的地方照样可以交叉——见交互演示里拖动「极限之差」滑块观察交叉点移动。

## 4. 一张表总结

| 性质 | 已知 | 可得 | 证明抓手 | 反向成立吗 |
| --- | --- | --- | --- | --- |
| ④ 有界性 | lim f = A 存在 | ∃M, δ：0<\|x−x₀\|<δ 时 \|f\| ≤ M | 取 ε = 1，M = \|A\|+1 | ✗ 局部有界 ⇏ 极限存在（sin(1/x)） |
| ⑤ 保号性（正向） | A > 0 | 附近 f > 0 | 取 ε = A/2 | ✗ 反例 2.5x² |
| ⑤ 保号性（反向） | 附近 f ≥ 0 | A ≥ 0 | 反证法 | — |
| ⑥ 不等式（正向） | A > B | 附近 f > g | 令 h = f−g，用 ⑤ | ✗ 反例 0.5+2.5x² |
| ⑥ 不等式（反向） | 附近 f ≥ g | A ≥ B | 归到 ⑤ | — |

## 5. 一句话记忆

> **从极限推函数，严格号能保住；从函数推极限，严格号一定降级成非严格号。**

配套做题直觉：题目说「已知 f(x) > 0，证明 A > 0」——条件不够，必然还要补一个信息（如 f 连续且在某点 > 0、或能先证明 A ≠ 0）。
