## 一、一句话结论

> 这一步**不是算出来的，是判符号判出来的**。

题目本身不是未定式（不是 `0·∞`、`∞/∞` 这类），所以不需要洛必达、不需要等价替换。只要把三个因子各自「去哪」确定下来，符号乘一乘，答案当场就出来了。

---

## 二、原题

```
lim (arctan x) · e^(−x) · x
x→−∞
```

## 三、逐步拆解：三个因子分别去哪

把 `x → −∞` 代入每个因子，逐个看：

| # | 因子 | x → −∞ 时趋向 | 性质 | 符号 |
| --- | --- | --- | --- | --- |
| 1 | `arctan x` | `−π/2 ≈ −1.5708` | **非零有限常数** | **−** |
| 2 | `e^(−x)` | `+∞`（`−x → +∞`，指数爆炸） | 无穷大 | **+** |
| 3 | `x` | `−∞` | 无穷大 | **−** |

于是：

```
(−π/2) · (+∞) · (−∞)
```

**第 1 步**：先把负常数和正无穷结合

```
(−π/2) · (+∞) = −∞          （负数 × 正无穷 = 负无穷）
```

**第 2 步**：再乘第 3 个因子

```
(−∞) · (−∞) = +∞            （负 × 负 = 正）
```

这就是讲义那行 `(−π/2)·(+∞)·(−∞) = +∞` 的全部内容。

---

## 四、这个写法为什么是合法的？

用的是**极限的乘法法则**：

> 有限个因子相乘，若每个因子的极限都存在（有限数或**定号**的无穷大），则乘积的极限 = 各因子极限之积。

三个条件都满足：

1. 因子个数有限（3 个）；
2. 每个因子的极限都存在——`arctan x` 收敛到常数 `−π/2`，另两个是**定号**无穷大；
3. **没有出现 `0 · ∞`**。

所以可以直接把三个极限相乘。反之，如果是 `lim(x→0) (1/x) · x` 这种 `∞ · 0`，就不能这么拆，得先变形。

> **判断口诀**：先看是不是未定式。不是未定式 → 直接代；是未定式 → 才上手段（等价替换 / 洛必达 / 泰勒 / 通分 / 取对数）。
> 本题三个因子都「有确定去向」，压根不是未定式。

## 五、三个容易踩的坑

| 坑 | 错法 | 为什么会错 | 正确做法 |
| --- | --- | --- | --- |
| **坑 1** | 认为 `arctan x → +π/2` | `arctan x → +π/2` 只在 `x → +∞` 成立；这里 `x → −∞`，是 `−π/2` | 记牢：`arctan(+∞) = +π/2`，`arctan(−∞) = −π/2`；值域 `(−π/2, π/2)`，单调递增 |
| **坑 2** | 把 `(∞)·(∞)` 当成未定式，去套洛必达 | `∞·∞` 永远是 `∞`，只是要判符号，不是未定式 | 直接按符号运算：负 × 负 = 正 |
| **坑 3** | 结论只写 `= ∞` | `+∞` 和 `−∞` 在后续（极限存在性、渐近线、间断点分类）里是两回事 | 永远带符号 |

**坑 1 的代价最大**：如果误判成 `+π/2`，符号链变成 `(+)·(+)·(−) = −`，答案会从 `+∞` 变成 `−∞`——方向完全反了。这一点可以在交互页上点「误当成 +π/2」按钮，亲眼看到结果翻号。

## 六、符号速判表（可直接背）

| 运算 | 结果 |
| --- | --- |
| 非零常数 × 无穷大 | 无穷大，符号 = 常数符号 × 无穷大符号 |
| `(+∞) · (+∞)` | `+∞` |
| `(+∞) · (−∞)` | `−∞` |
| `(−∞) · (−∞)` | `+∞` |
| `c · (+∞)`（`c > 0`） | `+∞` |
| `c · (+∞)`（`c < 0`） | `−∞` |
| `0 · ∞` | **未定式**，另想办法 |

## 七、本题的「标准写法」参考

更规范的书写方式是**先提非零常数因子**：

```
原式 = lim (arctan x) · lim [ x · e^(−x) ]
      = (−π/2) · lim (x / e^x)          ← 当 x→−∞，分母 e^x → 0⁺
      = (−π/2) · (−∞)                    ← 分子 −∞，分母 0⁺
      = +∞
```

两种写法都对。讲义的写法更省事（直接判三个因子的符号），学会之后这类题基本可以一行出答案。

## 九、延伸检验（自己动手）

用同样的「定位 + 定号」思路，试着直接写出下列极限（不需要完整过程）：

1. `lim (x→−∞) (arctan x) · x` → ?
2. `lim (x→+∞) (arctan x) · e^(−x) · x` → ?
3. `lim (x→−∞) (arctan x) · e^(x) · x` → ?

<details>
<summary>提示（点开看）</summary>

1. `(−π/2)·(−∞) = +∞`
2. `(+π/2)·(0⁺)·(+∞)` —— 出现 `0·∞`，**是未定式**，不能直接判。化成 `x / e^x`（`∞/∞`），洛必达一次得 0，故结果为 `0`。
3. `(−π/2)·(0⁺)·(−∞)` —— 同样是 `0·∞` 未定式。把 `x·e^x` 写成 `x / e^(−x)`，当 `x→−∞` 时分子 `−∞`、分母 `+∞`，是 `∞/∞` 型；洛必达一次得 `1 / (−e^(−x)) = −e^x → 0`，故结果为 `0`。

**对比记忆点**：第 1 题没有指数因子，`∞·∞` 直接判；第 2、3 题因为有指数因子制造了 `0·∞`，必须先变形。这说明**指数函数的存在经常会把「直接判」变成「未定式」**。
