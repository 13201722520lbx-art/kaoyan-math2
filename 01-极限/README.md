# 第 1 章　极限

> 状态：🔵 进行中　｜　更新时间：2026-09-24

## 一、本章知识框架

1. **数列的极限**
   - 数列极限定义（ε-N 语言）
   - 收敛数列的性质：唯一性、有界性、保号性、与子数列的关系
   - 存在准则：单调有界准则、夹逼准则
2. **函数的极限**
   - 自变量趋于有限值／无穷时的极限定义（ε-δ、ε-X）
   - 左极限、右极限，极限存在的充要条件
   - 函数极限的性质（唯一性、局部有界性、局部保号性）
3. **无穷小与无穷大**
   - 无穷小的定义与性质（有限个无穷小之和／积仍为无穷小；有界函数 × 无穷小 = 无穷小）
   - 无穷小的比较：高阶、同阶、等价、k 阶无穷小
   - 等价无穷小替换及其使用条件
   - 无穷大与无穷小的关系
4. **极限的计算方法**
   - 四则运算法则
   - 两个重要极限：`lim(x→0) sinx/x = 1`，`lim(x→∞)(1+1/x)^x = e`
   - 未定式的分类与处理：`0/0`、`∞/∞`、`0·∞`、`∞-∞`、`1^∞`、`0^0`、`∞^0`
   - 常用手段：等价无穷小、洛必达法则、泰勒展开、夹逼准则、定积分定义
5. **函数的连续性与间断点**
   - 连续的定义、左右连续、连续与极限的关系
   - 间断点及分类：第一类（可去、跳跃）、第二类（无穷、振荡）
   - 闭区间上连续函数的性质：有界性、最值定理、介值定理、零点定理

## 四、常用等价无穷小（x → 0）

| 函数 | 等价形式 |
| --- | --- |
| sin x, tan x, arcsin x, arctan x | ~ x |
| ln(1 + x) | ~ x |
| eˣ − 1 | ~ x |
| 1 − cos x | ~ x²/2 |
| (1 + x)ᵃ − 1 | ~ a x |
| aˣ − 1 | ~ x ln a |
| x − sin x | ~ x³/6 |
| tan x − x | ~ x³/3 |
| x − ln(1 + x) | ~ x²/2 |

> 使用注意：等价替换通常只适用于**乘除**因子，加减项中随意替换会出错（除非用泰勒展开精确到同阶）。
